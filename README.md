# OpsPilot AI

OpsPilot AI is the growing capstone for the AI Engineering Mastery Lab.

The project will become an industrial device reliability and field-service copilot. It will begin as a small FastAPI device API and grow only as the corresponding roadmap topics are learned.

## Learning rule

- Add one small feature at the end of each relevant module.
- Do not implement later technologies before they are taught.
- Attempt exercises before receiving a complete solution.
- Add tests where appropriate.
- Record important mistakes and decisions in `docs/PROGRESS.md`.
- Keep concise topic evidence in `docs/learning/`; code and exercises remain the priority.

## Planned growth

1. FastAPI device endpoints using in-memory data
2. Pydantic request and response validation
3. Layered backend structure
4. PostgreSQL, SQLAlchemy, migrations and ETL
5. Next.js and TypeScript operations dashboard
6. Simulated device events, MQTT, Redis and background workers
7. Rule-based alerts followed later by ML anomaly detection
8. RAG over manuals and troubleshooting documents
9. LangGraph investigation workflows
10. MCP diagnostic tools with human approval for actions
11. Automated tests and AI evaluation
12. Docker, CI/CD, cloud deployment and observability

No physical hardware is required. Python-based simulated devices will be used first. An ESP32 or Raspberry Pi can be connected much later as an optional extension.
